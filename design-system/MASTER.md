# DOZA — Design System (Master)

Источник правды для UI сайта и CRM. Стиль вдохновлён логотипом: золотая градиентная серифная надпись на глубоком тёмном фоне.

## Mood

Люкс с лоском. Тёмная база, тёплое золото, тёплое дерево, ботаническая зелень.
Сдержанно, дорого, тактильно. Никакой кричащей яркости.

## Типографика

- Заголовки: **Cormorant** (serif), вес 400–600, широкий трекинг для акцентов
- Текст/UI: **Montserrat** (sans), вес 300–600
- Логотип-надпись: Cormorant 600, буквенный интервал ~0.15em, золотой градиент

```css
@import url('https://fonts.googleapis.com/css2?family=Cormorant:wght@400;500;600;700&family=Montserrat:wght@300;400;500;600;700&display=swap');
```

Tailwind: `font-serif: Cormorant`, `font-sans: Montserrat`.

## Эффекты

- Мягкие тени, тёплое золотое свечение на CTA (`box-shadow: 0 0 24px rgba(201,162,75,.25)`)
- Тонкие золотые/деревянные бордеры (`1px`, низкая прозрачность)
- Плавные переходы 200–300ms (color/opacity/transform)
- Лёгкий film grain / зернистость на hero (опционально, через SVG noise)
- Botanical-акценты: тонкие SVG-веточки/листья как разделители

## Анти-паттерны

- ❌ Яркие/блочные «детские» цвета
- ❌ Эмодзи вместо иконок (только SVG — Lucide)
- ❌ Чистый `#000`/`#FFF` — использовать тёплые оттенки базы
- ❌ Hover со scale, ломающим layout

## Доступность

- Контраст текста ≥ 4.5:1 (ivory на ink проходит)
- Видимые focus-ring (золотой)
- `prefers-reduced-motion` уважается
- Тач-таргеты ≥ 44px
