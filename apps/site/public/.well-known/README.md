# Служебные файлы подтверждения владения доменом

Всё, что лежит в этой папке, отдаётся по `https://doza-parfum.by/.well-known/...`
— Astro раздаёт `public/` из корня, а nginx проксирует сюда всё, кроме
`/.well-known/acme-challenge/` (его забирает certbot для продления сертификата).

## Apple Pay

Файл `apple-developer-merchantid-domain-association` уже лежит здесь — им Apple
подтверждает, что домен наш. Внутри JSON с `pspId` магазина bePaid; имя менять
нельзя, расширения у файла нет.

Что осталось сделать в личном кабинете bePaid после деплоя:

1. Проверить, что открывается
   `https://doza-parfum.by/.well-known/apple-developer-merchantid-domain-association`
   — должен отдаться этот файл со статусом 200.
2. Вкладка **Apple Pay** → выбрать магазин → «Зарегистрировать» → «Применить».
3. Попросить менеджера bePaid активировать Apple Pay. После активации он
   появится в списке активных брендов магазина.

**В коде для этого ничего не нужно.** Apple Pay — не способ оплаты, а кошелёк
внутри карточной: шлюз показывает кнопку сам, тем покупателям, чьё устройство
её поддерживает. См. комментарий в `packages/shared/src/bepaid.ts`.
