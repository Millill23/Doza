# Служебные файлы подтверждения владения доменом

Всё, что лежит в этой папке, отдаётся по `https://doza-parfum.by/.well-known/...`
— Astro раздаёт `public/` из корня, а nginx проксирует сюда всё, кроме
`/.well-known/acme-challenge/` (его забирает certbot для продления сертификата).

## Apple Pay

Чтобы кнопка Apple Pay появилась на платёжной странице bePaid, Apple должна
убедиться, что домен наш. Для этого:

1. В личном кабинете bePaid — вкладка **Apple Pay** → **Править** → активировать
   сертификат провайдера (галочка о согласии с условиями Apple).
2. Скачать файл `apple-developer-merchantid-domain-association`.
3. Положить его **в эту папку** (имя менять нельзя, расширения у файла нет).
4. Задеплоить и проверить, что открывается:
   `https://doza-parfum.by/.well-known/apple-developer-merchantid-domain-association`
5. Вернуться в кабинет, выбрать магазин и нажать «Зарегистрировать» → «Применить».

Без выложенного файла аккаунт-менеджер bePaid не сможет завершить регистрацию.

Проверено, что путь работает: файл без расширения отдаётся со статусом 200.
